#+title: Notes

A site is a tree, directories are edges, and pages, forms and resources are nodes.

#+begin_src clojure
(ns forest
  (require [pbnj.routing as :r]))

{
 :site/name "Forest"
 :site/database #url "sqlite://..."
 :site/backend :pbnj.backend/php
 :site/routes
 (r/routes
  (r/page "/" :name "root" :to #pbnj/path "welcome/index" :via :get) ;; :via isn't required here since :get is the default
  (r/resource "entities" :doc "The core entities of the directory"
   (r/resource "reviews")
   (r/resource "images")
   (r/resource "links")
   (r/resource "categories")
   (r/resource "locations"
    (r/form "geo" :formats #{:format/json}))))
}
#+end_src

* Paths
Indicated with the #pbnj/path reader macro, paths are resolved by the system by first looking for resource file by type (e.g. HTML, CSS, PHP, JavaScript, or static assets). Then it will look for a source file by type (Phel, ClojureScript, Clojure, etc).

* Tree

#+begin_src clojure
{
 "/" {:route.tree/get #file "resources/welcome/index.html"
      :route.tree/children
      {"entities"
       {:route.tree/get #pbnj/path "entities/list"
        :route.tree/post #pbnj/path "entities/create"
        :route.tree/children
        {"add" {:route.tree/get #pbnj/path "entities/add"}
         "edit" {:route.tree/get #pbnj/path "entities/edit"}
         ":id"
         {:route.tree/get #pbnj/path "entities/show"
          :route.tree/put #pbnj/path "entities/update"
          :route.tree/delete #pbnj/path "entities/remove"}
        }

        }}
}
