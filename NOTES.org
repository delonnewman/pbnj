#+title: Notes

A site is a tree, directories are edges, and pages, forms and resources are nodes.

#+begin_src clojure
(ns forest
  (require [pbnj.routing as :r]))

{
 :site/name "Forest"
 :site/database {:db/url "sqlite://..."}
 :site/backend :site.backend/php
 :site/routes
 (r/routes
  (r/page "/" :name "root" :to #path "welcome/index" :via :route.method/get) ;; :via isn't required here since :get is the default
  (r/resource "entities" :doc "The core entities of the directory"
   (r/resource "reviews")
   (r/resource "images")
   (r/resource "links")
   (r/resource "categories")
   (r/resource "locations"
    (r/form "geo" :formats #{:format/json}))))
}
#+end_src

* Paths
Indicated with the #path reader macro, paths are resolved by the system
by first looking for resource file by type (e.g. html, css, php, javascript).
If nothing is found it will look for an action that coresponds to the path
within the root namespace.
